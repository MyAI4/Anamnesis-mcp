# Contributing to Anamnesis MCP

Contributions are welcome under the BUSL 1.1 licence terms. Please open an issue before submitting a PR for significant changes.

## Contributor Licence Agreement

A Contributor Licence Agreement (CLA) is required for all contributions. This is standard practice for BUSL projects and protects both contributors and the project. You will be prompted to sign the CLA when you open your first pull request.
